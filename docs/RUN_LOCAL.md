# 在国内电脑上本地运行（不依赖 VPN）

## 先准备

完整下载并解压项目。确认同一层能看到 `dist`、`scripts`、`package.json`。不要在压缩包内部直接运行，也不要双击 `dist/index.html`。

## Windows

1. 若电脑未安装 Node.js，打开 https://nodejs.org/ 下载并安装 LTS 版本；安装后重新打开文件夹。
2. 双击 `启动网站.cmd`。如已安装 Python 3，启动器也可使用 Python。
3. 保持命令窗口开启，在浏览器输入 `http://localhost:8080`。
4. 点击“开启五花手势互动”或进入单页点击“开启手势体验”，按提示允许摄像头。
5. 不用摄像头也能点击自动演示或使用滑块。结束时关闭网页，在命令窗口按 `Ctrl+C`。

也可在项目文件夹地址栏输入 `cmd` 回车，再输入 `npm start`。

## macOS / Linux

安装 Node.js 后，在项目文件夹的终端运行 `npm start`，浏览器打开 `http://localhost:8080`。

## 常见问题

- **找不到 node 或 Python**：先安装 Node.js LTS，关闭再打开命令窗口。无需执行 `npm install`。
- **端口被占用**：关闭先前的启动窗口，或执行 `node scripts/serve.mjs 8081`，打开 `http://localhost:8081`。
- **摄像头不能开启**：确认网址是 localhost，检查浏览器摄像头授权、Windows 隐私权限、摄像头是否被会议软件占用。
- **第一次准备略慢**：本地仍需读取并解码动画与模型；完成后会缓存。旧设备可先用自动演示或手动滑块。
- **局域网手机打不开/相机不可用**：默认服务只绑定本机，不对局域网开放。不要通过修改浏览器安全设置解决；跨设备演示应部署 HTTPS 站点。
- **新闻与购买入口打不开**：这些是外部联网链接，不属于离线资源。
- **两指合拢不到 0% 或张开不到 100%**：手完整入镜后使用网页校准按钮，保持拇指与食指端点姿势分别校准；检查左右手分工。

## 离线范围

下载完整文件并安装运行环境后，主页、五个花卉展厅、动画、菜谱和手势模型都随包提供。代码没有运行时 CDN 依赖。GitHub 下载、Node.js 安装、新闻与商品链接本身仍需要可用的网络；本地运行与在线站点能否从某地区访问是两件事。
